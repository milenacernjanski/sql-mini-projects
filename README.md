# SQL School Projects

## Overview
Collection of SQL practice exercises and small database projects completed during database coursework at Minot State University. Focus on table creation, basic queries, joins, and simple data analysis.

## What You'll Find Here
- **Table creation** and basic DDL exercises
- **Simple SELECT queries** with WHERE, GROUP BY, ORDER BY
- **JOIN practice** between related tables
- **Aggregate functions** (COUNT, SUM, AVG)
- **Basic database design** assignments

## Skills Practiced
- CREATE TABLE, INSERT, basic constraints
- SELECT with filters and sorting
- INNER JOIN, LEFT JOIN
- GROUP BY, HAVING
- Subqueries and basic views

## How to Run
1. Clone repository
2. Open MySQL Workbench or similar
3. Copy-paste .sql files or use SOURCE command
4. Run queries to see results

**Note:** Educational SQL exercises demonstrating foundational database skills from coursework.
